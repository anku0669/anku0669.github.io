# GATE 2027 Study Command Center

A static, browser-only study dashboard for GATE 2027.

## Features
- Exact countdown to 31 January 2027, 23:59:59 IST
- Days / hours / minutes / seconds remaining
- Total hours and seconds remaining
- Per-subject live study timers for 12 subjects
- Switching subjects automatically starts the selected subject
- Daily, weekly and monthly study tracking
- Four-phase roadmap through January
- Daily suggested study blocks
- Local browser storage and JSON export
- Responsive dark command-center UI

Live site: https://anku0669.github.io/gate/

No backend or external dependencies are required.
