01 / The engine

Built around the machine.
Not the cloud.

Large models do not always need every weight resident in fast memory at once. Qoralis is designed to manage where model data lives and when it moves.

01 — MAP

Understand the working set

Keep the model's active state and currently needed weights in the right memory tier.

02 — STREAM

Move data on demand

Bring less-frequently used weights from storage when the execution path needs them.

03 — EXECUTE

Use available compute

Run on CPU and supported accelerator backends, with platform and model compatibility in mind.

03 / Quick start

Start local.
Stay in control.

Extract the Qoralis source bundle, install the Python package from its project directory, then launch the local CLI. Model downloads and accelerator requirements depend on the selected engine.

Review the upstream technical foundation ↗
# From the extracted qoralis-engine directory
python -m pip install .

# Start an interactive local session
qoralis chat

# Or launch the local API and browser UI
qoralis serve --model /path/to/model
qoralis ui
Compatibility note: Qoralis retains the original colibri Python import namespace and coli command as backward-compatible interfaces. Consult the source package documentation for supported models, formats and hardware.
