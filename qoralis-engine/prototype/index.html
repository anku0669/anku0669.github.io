REAL LOCAL INFERENCE

Run Qoralis on your own machine

This hosted prototype cannot access your computer's GPU, memory or model files. To use the real engine, install Qoralis locally and run its gateway and UI.

qoralis setup\nqoralis serve --model /path/to/your/model\nqoralis ui

Open the local UI address printed by the CLI. The local interface proxies requests to the gateway so streaming, health, profiling and expert data work without exposing your machine to this public website.
