MODEL CARD
Index formula: baseline = hazard × (0.25 + 0.75 × exposure/100) × (0.25 + 0.75 × vulnerability/100). Adapted index = baseline × each (1 − user-assumed intervention reduction). Coefficients are a transparent design choice for teaching. This is not a validated disaster, climate, food-system, casualty, or economic model.

REPRODUCIBLE WORKFLOW
Recommended steps before making a scientific claim
  1. Start from the primary dataset and read its variable dictionary and licence.
  2. Record the source URL, dataset version, model, scenario, region, time window and units.
  3. Predefine exclusions, missing-data handling and any outlier treatment.
  4. Compare more than one model or scenario where available; report spread, not just a single line.
  5. Keep model output separate from assumptions about trade, exposure, vulnerability and policy response.
  6. Export the analysis inputs and code so another person can reproduce the transformation.
