# Security policy

## Support status

This project is a research preview. No production support or service-level agreement is offered.

## Safety notice

Do not expose the API prototype to the public internet, use it for operational decisions, or connect it to a live industrial control network. It does not implement authentication, authorization, tenant isolation or production hardening.

## Reporting a vulnerability

Do not publish sensitive vulnerability details in public issues. Do not include credentials, personal data, customer records, plant diagrams, network maps, process data or exploit details. Do not test against third-party systems or live facilities. Testing must be limited to systems you own or are explicitly authorized to assess.

A dedicated coordinated-disclosure contact will be established before a production release.
